# 简介

FindText 是一个 AHK 库，可以替代内置的 ImageSearch 功能，并包含许多附加功能。FindText 主要用于在屏幕上快速查找图形（图像），其匹配精度比 ImageSearch 高。它将屏幕上抓取一个小图像转换成黑白图像（类似于 ASCII 艺术），然后再将黑白图像转换成单行文本。使用 FindText 时，它会截取屏幕截图，将屏幕截图中的每个像素也转换成黑白，然后尝试将抓取的图像与屏幕截图进行匹配。由于像素变成了黑白，要比较的次数要少得多（红、绿、蓝需要比较三次、黑白只需要比较一次），所以匹配速度要比 ImageSearch 快。

FindText 的一些优点：

1）它不需要图像文件，而是使用图像的文本表示。该函数将屏幕的图像抽象为具有代表意义的“0”（“0”=黑色像素=文本像素）和“_”（“_”=白色像素=背景像素），它们依次排列变成一行数字和字母序列。因为这是一种抽象，而不是逐位比较，所以它可以实现快速匹配及轻松调整容错。

2）它比ImageSearch更快，在我的测试中大概快了10%（在有些用例中甚至可能快2-3倍）。

3）提供了轻松存储及在脚本中获取图像的函数。

4）使用 BindWindow，实现了当窗口藏在其他窗口后面时也能使用 FindText。

5）允许创建简单的自定义 OCR 函数。

## 入门指南

下载 FindText.ahk 后，我建议将其放入Lib 文件夹，然后使用以下命令将其包含在您的脚本中：

```AutoHotkey
#include <FindText>
```

完成上述操作后，您可以通过将已实现的图像搜索替换为 FindText().ImageSearch 来加快其速度，如下所示：

```AutoHotkey
ImageSearch, OutputVarX, OutputVarY, X1, Y1, X2, Y2, ImageFile
 ; 变成这样
FindText().ImageSearch(OutputVarX , OutputVarY, X1, Y1, X2, Y2, ImageFile)
```

## FindText 主函数

以下内容主要摘自 FindText.ahk 的顶部描述区域（并添加了一些内容）：

```AutoHotkey
returnArray := FindText(
    OutputX --> 该变量用于存储找到的第一张图片中心的 X 坐标。OutputX 也可以设为"wait"、"wait1" (appear) 或"wait0" (disappear)，以使 FindText 要么等待文本出现或消失。如果将 OutputX 留空，则不进行搜索，并返回一个 FindTextClass 实例：在 FindText().Click 示例中使用了这样的代码，等价于 FindText(,,,,,,,,Text).Click （Text 会被忽略）。调用 FindText 执行搜索的最简单形式为 FindText(X,,,,,,,,Text).
    , OutputY --> 该变量用于存储找到的第一张图片中心的 Y 坐标。如果 OutputX 设为 "wait"，则 OutputY 可以设置为等待的秒数，负数表示无限等待。[/list]
    , X1 --> 搜索区域左上角的 X 坐标
    , Y1 --> 搜索区域左上角的 Y 坐标
    , X2 --> 搜索区域右下角的 X 坐标
    , Y2 --> 搜索区域右下角的 Y 坐标
    如果 X1, Y1, X2, Y2 都设为 0 （默认值），则 X1 和 Y1 会被设为 -150000，X2 和 Y2 被设为 150000。这样会将搜索区域设为整个屏幕以及所有不在屏幕上的东西也包括在内。
    , err1 --> 文本的容错比例（text=黑色="o"）（0.1=10%）。
    , err0 --> 背景的容错比例（background=白色="_"） （0.1=10%）
    如果 err1 和 err0 都为 0，并且没有找到匹配项，则 FindText 会自动使用 0.05=5% 错误容限再次进行搜索。为避免这种情况，可以将 err1 和 err0 指定为很小的一个值（如 0.000001，很接近 0，但是不等于 0）。
    , Text --> 可以是多个文本形式的图片，图片之间用 "|" 分隔
    , ScreenShot --> 取值为 0 时，使用上一次截屏，默认为 1（每次都重新截屏）
    , FindAll --> 取值为 0 时，找到第一个结果后立刻返回，默认为 1（查找全部结果）
    , JoinText --> 用于组合查询：可以是 1，也可以是要查找的单词数组，默认为 0
    , offsetX --> 设置组合查找时 X 方向最大文本偏移量
    , offsetY --> 设置组合查找时 Y 方向最大文本偏移量
    , dir --> 指定搜索方向，共9种取值：
    1 ==> ( 从左到右 ) 从上到下
    2 ==> ( 从右到左 ) 从上到下
    3 ==>（从左到右）从下到上
    4 ==>（从右到左）从下到上
    5 ==>（从上到下）从左到右
    6 ==>（从下到上）从左到右
    7 ==>（从上到下）从右到左
    8 ==>（从下到上）从右到左
    9 ==>从中心向外
)
```

该函数返回一个包含所有查找结果的二阶数组（returnArray\[1\] 表示找到的第一个结果，returnArray\[2\] 表示找到的第二个结果，以此类推），每个结果都是一个关联数组：{1:X, 2:Y, 3:W, 4:H, x:X+W//2, y:Y+H//2, id:Comment}。 如果
没有找到图像，则 FindText 返回 0。

例如，如果返回变量名为“ok”，则 ok\[1\] 表示找到的第一个结果。
ok\[1\]\[1\] 和 ok\[1\]\[2\] 分别是找到的第一张图像左上角的 X 和 Y 坐标，
ok\[1\]\[3\] 是找到的图像的宽度，ok\[1\]\[4\] 是找到的图像的高度，
ok\[1\].x <==> ok\[1\]\[1\]+ok\[1\]\[3\]//2 <==> OutputX（找到的图像中心的 X 坐标），
ok\[1\].y <==> ok\[1\]\[2\]+ok\[1\]\[4\]//2 <==> OutputY（找到的图像中心的 Y 坐标），
ok\[1\].id 是注释文本，包含在 Text 的 <> 部分中。
如果 OutputX 设置为“wait”或“wait1”（出现）或“wait0”（消失），则超时表示失败并返回 0，其他值表示成功。如​​果等待出现且找到图像，则返回找到的数组对象。如果等待消失但未找到图像，则返回 1。

```AutoHotkey
FindText(X:="wait", Y:=3, 0,0,0,0,0,0,Text)   ; Wait 3 seconds for appear
FindText(X:="wait0", Y:=-1, 0,0,0,0,0,0,Text) ; Wait indefinitely for disappear
```

更多注意事项：

- 返回的所有坐标均相对于屏幕（如同在 CoordMode Screen 模式下）。要转换为相对坐标，请使用转换函数 ScreenToWindow 和 ScreenToClient。
- 所有颜色均为十六进制 RGB 格式。
- FindText 函数对屏幕 DPI 敏感，这意味着使用一种 DPI 捕获的图像/文本在另一种 DPI 下将无法正常工作。为确保用户使用正确的 DPI，请使用内置变量 A_ScreenDPI 进行检查。
- 使用多个显示器时，请勿将 X1、Y1、X2、Y2 设置为 0、0、A_ScreenWidth、A_ScreenHeight，因为这只会捕获主显示器。建议将其留空（默认值 -150000、-150000、150000、150000 应该足够大），或使用与默认值类似的大值。

对于以下示例，请使用画图程序打开第 1 节中提供的 Examples.png 文件。然后，在新脚本中运行代码，或者将不包含 #include 行的代码复制到 FindText GUI 代码框中，然后按“测试”。

## (3) ImageSearch、PixelSearch、PixelCount、GetPixelColor

FindText().ImageSearch 是 FindText 的包装函数，它更易于使用。它还可以像 AHK 原生函数 ImageSearch 一样接受图像文件（但不支持 *IconN 等选项），并且它支持不同的 CoordMode（FindText 总是返回相对于屏幕的坐标，但 FindText().ImageSearch 可以使用任何一个由 CoordMode Pixel 命令设置的坐标模式，例如 Window 或 Client 坐标模式）。

FindText().ImageSearch(OutputVarX, OutputVarY, X1, Y1, X2, Y2, TextOrImageFile, Screenshot:=1, FindAll:=0)

returnValue := FindText().ImageSearch(

OutputVarX, OutputVarY --> 存储找到图像中心的 X 和 Y 坐标的变量名。除非使用 CoordMode 来更改坐标模式，否则坐标是相对于活动窗口的。
,X1, Y1 --> 搜索矩形左上角的 X 和 Y 坐标。除非使用 CoordMode 来更改坐标，否则坐标是相对于活动窗口的。
,X2, Y2 --> 搜索矩形右下角的 X 和 Y 坐标。除非使用 CoordMode 来更改坐标，否则坐标是相对于活动窗口的。
, TextOrImageFile --> FindText 文本或图像文件的文件名
, Screenshot --> 如果值为 0，则使用最后的截图，默认为 1（每次重新截图）
, FindAll --> 如果值为0，则在找到第一个结果后返回，默认为1（查找所有结果）

)

如果搜索成功，returnValue 将被设置为 1，否则为 0。

如果搜索成功，ErrorLevel 将被设置为 0，否则为 1。

例子：

```AutoHotkey
#include <FindText>
if FindText().ImageSearch(X,Y,,,,, A_ScriptDir "\Examples.png") ; Looks for the image in Examples.png on the screen
    FindText().MouseTip(X, Y)
if FindText().ImageSearch(X,Y,,,,, "|<auto>*159$40.0000k000003000000A00DVUnw7lr6371nUAMAA630FUkkkAT63330rgMAAA1kFUkkkD363330wAAAA62vkvkkQtt1v1kS8") ; Looks for the "auto" image contained in the Text
    FindText().MouseTip(X, Y)
```

以下示例使用±10的颜色变化范围，并将黑色设置为透明色：FindText().ImageSearch(X,Y,,,,, "*10*TransBlack A_ScriptDir "\\Examples.png")

FindText().PixelSearch是 FindText 函数中内置 PixelSearch 函数的替代方案。与内置版本类似，其坐标系取决于 CoordMode，这意味着除非另行设置，否则坐标将相对于活动窗口。FindText

().PixelSearch(OutputVarX, OutputVarY, x1, y1, x2, y2, ColorID, Variation:=0, ScreenShot:=1, FindAll:=0)

returnArray := FindText().PixelSearch(
OutputVarX、OutputVarY --> 用于存储第一个找到的匹配像素的 X 和 Y 坐标的变量名。除非使用 CoordMode 更改了坐标系，否则坐标相对于活动窗口。
,X1、Y1 --> 要搜索的矩形左上角的 X 和 Y 坐标。除非使用 CoordMode 更改了坐标系，否则坐标相对于活动窗口。
,X2、Y2 --> 要搜索的矩形右下角的 X 和 Y 坐标。除非使用 CoordMode 更改了坐标系，否则坐标相对于活动窗口。
,ColorID --> 要搜索的十六进制颜色 ID，默认为红绿蓝 (RGB) 格式 (RRGGBB)。可以使用 \| 字符分隔多个颜色。
，Variation --> 一个介于 0 和 255（含）之间的数字，用于指示颜色的红色、绿色和蓝色分量强度允许的色调变化数量
。Screenshot --> 如果值为 0，则使用上次的屏幕截图；默认值为 1（每次都使用新的屏幕截图）
。FindAll --> 如果值为 0（默认值），则在找到第一个结果后返回；如果值为 1，则查找所有结果。如果 FindAll<0，则仅返回找到的像素数量。

如果搜索失败，则返回 0。否则，该函数返回一个包含所有查找结果的数组（returnArray\[1\] 表示找到的第一个结果，returnArray\[2\] 表示找到的第二个结果，以此类推），每个结果都是一个关联数组：{1:X, 2:Y, 3:W, 4:H, x:X+W//2, y:Y+H//2}。 示例

：

```AutoHotkey
ok := FindText().PixelSearch(,,,,,, "0xFFFFFF|0x000000") ; FFFFFF = black, 000000 = white
FindText().MouseTip(ok[1].x, ok[1].y) ; Displays first found black or white pixel
```

FindText().PixelCount 函数用于计算搜索区域中的像素数量。由于搜索区域可以小至 1 像素，因此也可以用它来检查特定颜色（或颜色范围）的像素。PixelCount

(x1:=0, y1:=0, x2:=0, y2:=0, ColorID:="", Variation:=0, ScreenShot:=1)

out := PixelCount(
x1:=0, y1:=0 --> 要搜索的矩形左上角的 X 和 Y 坐标。坐标相对于屏幕。
, x2:=0, y2:=0 --> 要搜索的矩形右下角的 X 和 Y 坐标。坐标相对于屏幕。
, ColorID:="" --> 要搜索的十六进制颜色 ID，默认为红绿蓝 (RGB) 格式 (RRGGBB)。允许使用多个颜色，用 \| 字符分隔。也支持颜色范围，例如 "RRGGBB-DRDGDB\|RRGGBB-DRDGDB".。
, Variation:=0 --> 介于 0 和 255（含）之间的数字，表示颜色的红色、绿色和蓝色分量强度允许的色调变化数量。
, ScreenShot:=1 --> 如果值为 0，则使用上次的屏幕截图；默认值为 1（每次都使用新的屏幕截图）。

如果搜索不成功，则返回 0。否则，返回找到的像素数量。 例如：

```AutoHotkey
out := FindText().PixelCount(0, 0, A_ScreenWidth, A_ScreenHeight, "FFFFFF")
```

GetPixelColor 函数
在 FindText 函数中没有像 PixelGetColor 那样的内置方法来获取屏幕上特定像素的颜色。幸运的是，我们可以编写一个包装函数来实现这个功能：

```AutoHotkey

GetPixelColor(x, y, screenshot:=1) {
if (A_CoordModePixel="Window")
FindText().WindowToScreen(x, y, x, y)
else if (A_CoordModePixel="Client")
FindText().ClientToScreen(x, y, x, y)
```

与内置的 PixelGetColor 函数类似，此包装函数使用 CoordMode 像素坐标。此外，每次都会重新截取屏幕截图，可以通过将截图参数设置为 0 来禁用此功能，这意味着像素颜色将取自上次截取屏幕截图的 FindText 调用。

## (4) 什么是 Text 文本？

```AutoHotkey
Text:="|<auto>*159$40.0000k000003000000A00DVUnw7lr6371nUAMAA630FUkkkAT63330rgMAAA1kFUkkkD363330wAAAA62vkvkkQtt1v1kS8" 
; From left to right: "|" is the separator
; "<auto>" means the id/comment of the Text is "auto"
; "*" is the capture mode, which in this case is Gray
; 159 is the Gray threshold value
; 40 (between $ and .) is the width of the original image
; 0000k000003000000A00DVUnw7lr6371nUAMAA630FUkkkAT63330rgMAAA1kFUkkkD363330wAAAA62vkvkkQtt1v1kS8 is the 64-bit representation of the image
```

文本字符串由 5 个部分组成：

1. 竖线字符 `|` 是图像分隔符。这意味着可以将多个图像依次连接起来，同时进行搜索（或用于组合搜索）。

```AutoHotkey
Text:="|<auto>*159$40.0000k000003000000A00DVUnw7lr6371nUAMAA630FUkkkAT63330rgMAAA1kFUkkkD363330wAAAA62vkvkkQtt1v1kS8" ; First set the Text variable to contain the "auto" image
Text.="|<hot>*152$29.U00010000200014000280004Hk7kzxktktVVUkX161V43A3286M24EAkA8UNUMF0lUUW1Xb1g31s1s" ; Then append the "hot" image to Text variable using the ".=" operator
ok:=FindText(X,Y,,,,,,,Text)
for k, v in ok
    FindText().MouseTip(v.x, v.y)
```

相当于：

```AutoHotkey
Text:="|<auto>*159$40.0000k000003000000A00DVUnw7lr6371nUAMAA630FUkkkAT63330rgMAAA1kFUkkkD363330wAAAA62vkvkkQtt1v1kS8|<hot>*152$29.U00010000200014000280004Hk7kzxktktVVUkX161V43A3286M24EAkA8UNUMF0lUUW1Xb1g31s1s"
ok:=FindText(X,Y,,,,,,,Text)
for k, v in ok
    FindText().MouseTip(v.x, v.y)
```

这会返回所有 `auto` 和 `hot` 图像的结果。

1. 尖括号 `<>` 之间的字符是图像的 `id` 或“注释”，可用于为图像命名。如果 `ok:=FindText(...)` 成功，则 `ok[1].id` 将包含找到的第一个图像的 id。id 可以包含任何字母、数字和符号（如果使用 AHK 的 Unicode 版本，则包括所有 Unicode 字符），但 `>` 和换行符除外。

```AutoHotkey
Text:="|<auto>*159$40.0000k000003000000A00DVUnw7lr6371nUAMAA630FUkkkAT63330rgMAAA1kFUkkkD363330wAAAA62vkvkkQtt1v1kS8" ; "<auto>" sets the id of the image to the word "auto".
Text.="|<hot>*152$29.U00010000200014000280004Hk7kzxktktVVUkX161V43A3286M24EAkA8UNUMF0lUUW1Xb1g31s1s" ; "<hot>" sets the id of the image to the word "hot".
ok:=FindText(X,Y,,,,,,,Text)
for k, v in ok {
    if v.id == "hot" {
        MsgBox, % "The ""hot"" image was found at X:" v.x " Y:" v.y
    }
}
```

1. `>` 和 `$` 之间的数字和符号定义了搜索模式。共有 5 种不同的模式，我们将在后面的“捕获模式”部分详细介绍。在这些 `auto` 图像的示例中，`*` 表示使用灰度模式，`159` 是阈值。
2. `$` 和 `.` 之间的数字是图像的像素宽度。此值不应手动更改，应使用“剪切”按钮进行修改。在第一个示例中，“auto”图像的宽度为 `40`。
3. `.` 之后的所有内容是图像的 64 位文本表示。此值不应手动更改，应使用“剪切”按钮进行修改。
4. 有一种未公开的方法可以在文本中包含 `err1` 和 `err0`，这将覆盖传递给 `FindText` 函数的 `err1` 和 `err0` 值。这可以通过在 id 后添加 `[err1,err0]` 来实现：

```AutoHotkey
Text:="|<mycomment>[0.2,0.1]*197$15.1U8A11U8C11k8600s0700Q01U004" ; Overrides err1 to be 0.2 (20%) and err0 to be 0.1 (10%)
ok:=FindText(X,Y,,,,,0.3,0.3,Text) ; Even though err1 and err0 are set to 0.3, instead the values 0.2 and 0.1 will be used for the search
```

## 5) 捕获模式

### 1. 灰度模式

在灰度模式下，每个像素的灰度值（0-255，其中 0 为纯黑，255 为纯白）都会与一个阈值进行比较。如果某个像素的灰度值超过阈值，则该像素将被转换为白色（白色=背景=0），否则转换为黑色（黑色=文本=1）。因此，任何比阈值更暗的像素都将被转换为黑色，任何比阈值更亮的像素都将被转换为白色。阈值 255 会将整幅图像转换为黑色，并匹配搜索范围内的所有内容。

在文本模式下，灰度模式由星号 (*) 字符及其后的阈值标识。

```AutoHotkey

Text:="\|\<auto>*159$40.0000k000003000000A00DVUnw7lr6371nUAMAA630FUkkkAT63330rgMAAA1kFUkkkD363330wAAAA62vkvkkQtt1v1kS8" ; The "*" after "<auto>" means that Gray mode is being used, the threshold value is 159 (found between * and$), image width is 40 pixels (found between $ and .)
```

1. GrayDiff（灰度差分）。每个像素都会被逐一比较，如果被比较像素周围的任何像素（总共比较 8 次）的灰度值超过该像素的灰度值加上阈值，则被比较像素将被变为黑色，否则将被变为白色。本质上，它突出了形状的边缘，因为最大的灰度差出现在对比度高的区域，例如边缘，而纯色区域会被变为白色。在 Examples.png 的“灰度与 GrayDiff 示例”中，如果我们希望 FindText 只找到最右边的两个方块（纯色），那么使用灰度模式无法实现，但 GrayDiff 可以将它们分开（示例如下）。
   在文本格式中，GrayDiff 模式用 ** 字符标识，其后是阈值。

```AutoHotkey
#include <FindText>
Text:="|<solidcolorbox>**50$54.zzzzzzzzzU00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001U00000001zzzzzzzzzU" 
; "**" means GrayDiff mode, threshold is set to 50, the image in Text is 54 pixels wide
ok:=FindText(X,Y,,,,,,,Text)
for k, v in ok
    FindText().MouseTip(v.x, v.y)
```

1. 颜色。在 FindText 图形用户界面中，点击图像上的一个像素即可选中该像素的颜色并将其定义为“黑色”。然后，可以使用相似度缩放器将相似颜色（同一颜色的不同色调）也包含在内，点击“Color2Two”按钮即可应用滑块所做的更改。
   在文本模式下，“颜色”模式由所选颜色的十六进制表示、@ 符号和滑块值（从 0.00 到 1.00，1.00 表示 100% 相似度）标识。

```AutoHotkey
Text:="\|<>505050@1.00$29.U00010000200014000280004Hk7kzxktktVVUkX161V43A3286M24EAkA8UNUMF0lUUW1Xb1g31s1s"
; Only the color 505050 will be considered Text (black pixels)
; Similarity is set to 1.00 (100%), so color-wise only exact matches are allowed
```

1. 颜色位置 (ColorPos)。点击图像上的一个像素，即可确定该像素相对于图像左上角的位置，并将该像素的颜色用于黑白转换。因此，此模式可以查找单一颜色的图案，其中颜色取自指定的像素位置。与颜色模式类似，此模式也提供了一个相似度滑块，用于检测相似颜色。
   在文本模式下，颜色位置由“#”符号后跟一个数字（表示所选像素的位置，从左上角开始，从左到右，再从上到下），然后是“@”符号和滑块值。

```AutoHotkey
Text:="|<>#49@0.90$47.zzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzz07zzzzzy07zzzwDwQ7zzzsTsyDzzzkzlwQ1w007Xsk1k00D7V11127yC2D2DwDw08T47sTs0kyA0kzlzVwQ0VzXz3szV3z7z7VzW7yDy22667wTy0A0A1szy0s0w3zzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzz"
; # means ColorPos mode
; 49 means that the 49th pixel (from left to right, top to bottom) is considered "black". Since the image width is 47, then it is the second pixel in the second row
; 0.90 is the similarity value (90%)
```

1. 颜色差值。在 FindText 图形用户界面中，点击图像上的一个像素会选中该像素的颜色并将其定义为“黑色”。“ColorDiff2Two”按钮会使用选中的颜色将图像转换为黑白图像。现在，可以使用 R、G 和 B 上下调节框来选择允许的颜色差值（正负值，但不会从 255 到 0 或反之亦然）。例如，如果选中的颜色是 0098D9（十六进制 R=00，G=98，B=D9），并且 R 上下调节框设置为 1，则 FindText 将匹配颜色 0098D9 和 0198D9（但不会匹配 FF98D9，因为它不会循环）。然后，将 B 设置为 5 将匹配 0093D9 和 019DD9 之间的颜色。

```AutoHotkey
Text:="\|<>3F627F-00050A$51.zzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzk1zzzzzzy07zzzwDzlUTzzzVzyD3zzzwDzlwM1s007yDW06000zlsE0EEVzyA0D27wDzk0VsETVzy0ADW0ADzlzVwM0VzyDwD3w4DzlzVsTsVzyDy02467zlzk0k0k7yDz0C0C0zzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzw"
; The color defined as "black" is 3F627F
; Allowed color error margins are 00050A: 00 (0 in decimal) for red, 05 (5 in decimal) for green, 0A (10 in decimal) for blue.
```

1. 多色模式。选中“查找多色”复选框后，即可选择多个像素。“查找文本”功能将仅查找所选像素，并指定其相对坐标（第一个选定像素位于 x=0, y=0，后续像素均以此为基准）和颜色。例如，如果在此模式下选择了两个像素，“查找文本”功能将仅查找两个颜色相同且相对坐标相同的像素。可以使用 RGB 滑块调整误差范围。在文本模式下，“多色模式”由 ## 符号后跟 RGB 误差范围数值（0-255）标识。$ 符号后紧跟所选像素的相对坐标和颜色：例如，“0/0/3A8000,1/0/008000”表示将查找颜色分别为 3A8000 和 008000 的两个像素，其中 008000 必须位于 3A8000 右侧一个像素的位置。

多色模式也可用于查找保存为文件的图像。这可以通过指定文件位置而非单个像素来实现。FindText().ImageSearch 函数内部使用了此方法。

```AutoHotkey
Text:="|<>##1$0/0/3F627F,-7/1/FFFFFF"
; ## means MultiColor mode
; Error margin for RGB is 1
; Matches position for colors 3F627F (± 1 for each of R, G and B: matches everything between 3E617E and 406380), if the pixel 7 positions to left and 1 position down is of color FFFFFF (± 1 for R, G and B)

Text := "|<>##0$" A_ScriptDir "\Example.png" ; Using this Text in FindText would look for the image in Example.png located in the script directory, with RGB error margin set to 0
```

搜索图像文件时，可以指定一个或多个透明颜色，这意味着这些颜色将被忽略（类似于内置的 ImageSearch *Trans 选项）。这可以通过以下语法实现。##10-RRGGBB-RRGGBB... $ C:\\image.bmp。

 2. 使用尽可能小的搜索范围。这可以通过多种方式实现，最简单的方法是使用 WinGetPos 获取窗口位置和大小，从而将搜索范围限制在单个窗口内。

```AutoHotkey
WinGetPos, pX, pY, pW, pH, ahk_class MSPaintApp ; Get the Paint application location and size.
ok := FindText(X, Y, pX, pY, pX+pW, pY+pH,,, Text) ; Set the search range to only the Paint window
有时，搜索到的图像只会出现在特定区域，因此可以进一步调整搜索范围。在画图窗口中，如果我们对菜单栏和工具栏都不感兴趣，那么我们可以从顶部裁剪掉一定量的区域：
```

WinGetPos, pX, pY, pW, pH, ahk_class MSPaintApp ; Get the Paint application location and size.
ok := FindText(X, Y, pX, pY+150, pX+pW, pY+pH,,, Text) ; Set the search range to only the Paint window and crop by 150 pixels from the top to leave out the menubar and toolbar
2\. 使用尽可能小的图像。这可以通过使用 L3/R3/L/R/U/B/自动裁剪按钮裁剪捕获的图像来实现。3
. 使用尽可能小的误差范围。例如，将 err1 和 err0 都从 0 提高到 0.3 可能会导致搜索速度明显变慢（可能慢 5-10 倍）。4
. 如果要查找精确匹配项，请为 err1、err0 或两者都指定一个非常小的非零值。FindText 的默认行为是，如果 err1 和 err0 都设置为 0，则如果搜索失败，将自动尝试再次搜索，并将 err1 和 err0 设置为 0.05。当多次调用 FindText 来查找不同的图像时，这种额外的搜索会累积耗时。但这只有在 err1 和 err0 恰好为 0 时才会发生，这意味着，如果您例如将 err1、err0 或两者都设为 0.000001（这实际上是 0 但不等于 0）（只需要其中一个非零），则只会进行一次搜索（有效误差范围为 0.000001≈0）。

```AutoHotkey
FindText(X, Y,,,,,,, Text) ; If Text is not visible on the screen, then the search happens twice: first with err1 and err0 set to 0, then again with 0.05 (5% error margin)
FindText(X, Y,,,,,0.000001,, Text) ; If Text is not visible on the screen, then the search happens just once, looking for an exact match (0.000001≈0)
FindText(X, Y,,,,,0.05,0.05, Text) ; If Text is not visible on the screen, then the search happens just once, but leaves a small error margin of 5%
5. 如果要搜索多张图片，可以将文本合并为一个，只调用一次 FindText 函数；或者将 Screenshot 参数设置为 0，以便后续搜索。这样可以避免 FindText 函数多次截图，从而节省大量时间。
```
