## EmEditor 高级使用：配置、小说大纲与宏 API

这篇文章整理了几个常用场景：基础配置、按章节分割小说、小说大纲导航，以及 EmEditor 宏 API 的常见对象与方法。适合日常写作、文本处理和自动化脚本场景。

---

## 一、基础配置

### 1. 打开所有配置属性

依次点击：`工具 → 所有配置属性`

建议设置如下：

- 常规：勾选「显示行号」
- 常规：开启「自动换行」并设置为「窗口宽度」
- 段落标记：取消勾选「显示换行符」
- 大纲：类型设为「自定义」
- 取消勾选「使注释可折叠」
- 勾选「隐藏匹配的字符串 / 用正则表达式替换」
- 点击「添加」按钮，把下面的正则复制到「查找」项中，并勾选「正则表达式」

```bash
^[ 　\t]{0,4}(?:序章|楔子|正文(?!完|结)|终章|后记|尾声|番外|完本感言|第?s{0,4}[\d零一二两三四五六七八九十百千万壹贰叁肆伍陆柒捌玖拾佰仟]+?s{0,4}(?:章)).{0,30}$
```

这个规则适合小说或长文档中，对章节标题进行快速识别和筛选。

### 2. 宏与插件配置

路径：`宏 → 自定义宏 → 选项`

勾选：**使用 V8 作为 JavaScript 引擎**

这样可以更稳定地运行一些基于 JavaScript 的宏脚本，兼容性和扩展性都会更好。

## 二、按章节分割文件（手动操作指南）

这是在 EmEditor 中手动按章节分割文件的常用方法，适合小说、长文稿和资料整理。

### 操作步骤

1. 打开要分割的文件
2. 按 `Ctrl + F` 打开「查找」对话框
3. 切换到「正则表达式」模式
4. 输入用于匹配章节标题的正则表达式
5. 点击「全部查找」
6. 在结果窗口中选择「全部设为书签」
7. 点击菜单栏：`工具 → 分割文件`
8. 在弹出窗口中，选择「在每个书签行前」作为分割方式
9. 点击「下一步」并根据提示设置输出目录、文件命名规则等
10. 最后执行分割操作

### 说明

这种方法的关键在于：

- 正则表达式要尽量准确命中章节标题
- 书签位置会成为分割基点
- 分割后文件命名规则可以根据自己习惯进行设置

如果文档结构比较规则，效果会尤其好。

## 三、小说大纲

如果你在处理小说、长篇正文或章节型文档，可以利用 EmEditor 的大纲功能来快速定位内容。

### 步骤

1. 依次点击：`查看 → 大纲栏`
2. 再点击：`查看 → 大纲导航`
3. 让这两个选项处于启用状态
4. 点击底部的「属性」按钮
5. 在设置面板中：
   - 「类型」选择「自定义」
   - 取消勾选「使注释可折叠」
   - 勾选「隐藏匹配的字符串 / 用正则表达式替换」
   - 点击「添加」按钮
   - 将下面的规则添加到「查找」项中
   - 勾选「正则表达式」

```bash
(?:正文 )?(第)([―－\-─—壹贰叁肆伍陆柒捌玖一二两三四五六七八九十○〇零百千O0-9０-９]{1,12})(章|节|回|集|部|卷|篇)(.*)
```

保存设置后，左侧大纲栏会显示小说章节标题。点击其中任意标题即可跳转到对应位置。

### 适用场景

- 小说拆分
- 文档目录导航
- 章节快速跳转
- 架构化阅读

## 五、实用建议

1. 如果你处理的是小说或长文章，优先使用大纲和正则规则来快速定位章节。
2. 如果你需要批量处理大量文本，宏和 `FindInFiles` / `ReplaceInFiles` 会非常高效。
3. 对于书签和分割，多使用正则规则来提高稳定性。
4. 宏中尽量把逻辑拆成小步骤，方便调试和维护。

---

## 六、总结

EmEditor 的优势在于：

- 配置灵活，适合长文本和代码编辑
- 大纲功能适合小说和章节型作品
- 宏 API 能让重复操作自动化
- 正则表达式结合书签和分割功能，非常适合内容整理

如果你长期使用 EmEditor，熟悉这些配置和宏对象，会明显提升编辑效率。
